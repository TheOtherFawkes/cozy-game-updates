# Cozy Game — alpha download

**[Download the latest Android build](https://raw.githubusercontent.com/TheOtherFawkes/cozy-game-updates/main/CozyGame.apk)**, then open it on your phone to install.

The first time, Android asks you to allow installs from your browser or file manager. That's normal for apps from outside the Play Store. Installing a new build over the old one keeps your progress.

This is an early alpha: things will change, break and get rebalanced. Feedback: mrpinske@gmail.com

`version.json` is read by the game to tell you when a newer build is available.
